# 🎵 Full Stack Music Player (MERN Stack)

## 📌 Project Overview
This project is a **Full Stack Music Player web application** developed as part of my **MERN Stack Internship at WSA Webstack Academy**.  
The application allows users to **register, log in, browse music, and stream songs** using the **Jamendo public music API**.

It demonstrates **end-to-end full stack development** using the MERN architecture.

---

## 🎯 Internship Goals
- Understand full stack web development workflow
- Learn MERN Stack architecture and data flow
- Build REST APIs and connect frontend with backend
- Implement authentication and authorization using JWT
- Develop and test a complete working application

---
## 🏗 Architecture & Design
- Follows **MERN Stack architecture**
- React handles the user interface
- Express & Node handle backend logic
- MongoDB stores user data
- REST APIs connect frontend and backend
- Backend follows **MVC structure** (routes, controllers, models, middleware)

---

## ⚙️ Features
- User Signup & Login (JWT Authentication)
- Protected routes using authentication middleware
- Music data fetched from Jamendo API
- Music player with:
  - Play
  - Pause
  - Next
  - Previous
- Responsive UI
- Clean separation of frontend and backend

## ▶️ How to Use the Application

### Register / Login
- Create a new user account or log in with existing credentials
- Authentication is handled using JWT

### Access Music Player
- After successful login, users are redirected to the main music player
- Unauthorized users cannot access protected pages

### Browse Music
- Music tracks are fetched dynamically from the Jamendo Public Music API
- Songs are displayed with basic metadata

### Play Music
- Select a track to start streaming
- Use player controls:
  - Play
  - Pause
  - Next
  - Previous

### Session Handling
- User session is maintained using JWT
- On logout, access to protected routes is removed
